 ShopSmart Retail Analytics Dashboard

 Project Overview
This project analyses ShopSmart Retail's sales, products, customers, stores, returns, and inventory data using Microsoft Excel. The goal is to turn retail data into useful business insights that support management decision-making.

Tools and Techniques
- Microsoft Excel
- Data cleaning and formatting
- XLOOKUP for retrieving related information
- PivotTables and PivotCharts
- KPI cards and interactive slicers
- Executive dashboard design

Project Objectives
- Identify top-performing products, stores, and sales categories.
- Analyse monthly revenue trends.
- Explore customer purchasing patterns.
- Examine product returns and inventory levels.
- Present key findings to support business decisions.

Dashboard Features
The interactive dashboard includes:
- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Return Rate
- Inventory Value

It also includes charts for monthly sales trends, revenue by category and store, top products, and sales by state, with interactive filters.

Deliverables
- Excel analysis workbook
- Executive dashboard
- Business report

Key Learning Outcomes
This project strengthened my practical skills in data cleaning, Excel formulas, lookup functions, PivotTables, data visualisation, and business analysis.
